1. Personal Data and Privacy Policy

1.1. NiXeL, as an iol-app, does not have its own servers or user data storage, but is a graphical interface in the form of a mobile application for accessing the Internet of Labour (iol) platform with special access.

1.2. NiXeL prompts users to enter only the necessary data to provide the required functionality. This means that NiXeL requests from users only public data that is shown to other users, except for the necessary photos of documents for Verification. The user can hide a document from other users in their profile using the "Show to other users" toggle switch.

1.3. Identification documents provided for activation/verification are recommended to be hidden from other users. However, they will be accessible to iol moderators for manual user verification.

1.4. Any data provided in NiXeL is sent to the Internet of Labour platform. To exchange data with the platform, NiXeL uses the open-source module iolNet. Data exchange between NiXeL and the iol module iolNet can only be carried out securely in accordance with the iol protocol:
• communication via the iol protocol uses TLS/SSL Encryption unique to each connection and does not use http/https.
• graphical information, such as photos/drawings, is protected by the iol platform and is accessible only in iol-apps, while the delivery of graphical information to NiXeL uses a unique one-time token for each connection.
• application updates use the most reliable paths to avoid third-party attempts to interfere with user data of NiXeL and iol, including from Google Play and mobile device manufacturers

1.5. Additional recommendations on personal data protection are provided in the "Tips and recommendations" section of this Smart Contract T0.
