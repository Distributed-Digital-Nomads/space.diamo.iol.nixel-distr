1. Персональные данные и Политика конфиденциальности

1.1. NiXeL, как iol-апп, не имеет своих серверов и хранилищ данных пользователей, а является графическим интерфейсом в виде мобильного приложения для доступа к платформе Интернет Труда (iol) со особым доступом.

1.2. NiXeL предлагает пользователям вводить только необходимые данные для предоставления необходимого функционала. Это означает, что NiXeL запрашивает от пользователей только публичные данные, которые показываются другим пользователям, кроме необходимых фото документов для Верификации. Пользователь может скрыть документ от других пользователей в своём профиле используя переключатель «Показать другим пользователям».

1.3. Идентификационные документы, предоставленные для активации/верификации рекомендуются скрывать от других пользователей. Однако, они будут доступны модераторам iol для ручной верификации пользователя.

1.4. Любые данные предоставляемые в NiXeL отправляются в платформу Интернет Труда. Для обмена данными с платфомой NiXeL использует модуль с открытым исходным кодом iolNet. Обмен данными между NiXeL и iol модулем iolNet может осуществлять только защищёно в соответствии с протоколом iol:
• коммуникация по протоколу iol использует уникальной для каждого соединения TLS/SSL Encryption и не использует http/https.
• графическая информация, такие как фото/рисунки, защищена платформой iol и доступна только в iol-аппах, при этом доставка графической информации до NiXeL использует уникальный одноразовый токен для каждого соединения.
• обновление приложения использует максимально надежные пути для избегания попыток вмешательства третьих сторон в данные пользователей NiXeL и iol, включая со стороны Google Play и производителей мобильных устройств

1.5. Дополнительные рекомендации по защите персональных данных предоставлены в разделе «Советы и рекомендации» данного Смарт-контракта T0.
